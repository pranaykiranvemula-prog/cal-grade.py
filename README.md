# Student Grade Calculator - Python Data Processing Project
A Python app that reads student marks from a CSV file,
calculates grades automatically, and saves a report.
## Features
- Reads student data from CSV input file
- Calculates total marks, percentage, and grade for each student
- Displays formatted results table on screen
- Shows class statistics: average, highest, lowest, pass/fail count
- Saves complete results report to a new CSV file
## How to Run
1. Make sure Python is installed: python --version
2. Create a students.csv file with columns: Name, Subject1, Subject2...
3. Run: python grade_calculator.py
4. Results are shown on screen and saved to results.csv
## Grade Scale
A+ = 90%+ A = 80-89% B = 70-79% C = 60-69% D = 50-59% FAIL = below 50%
